# Independent arithmetic review

Review the following public, synthetic claim. No browsing or execution is required.

Claim: a machine produces 12 parts per hour for 2.5 hours, rejects 10% of those parts,
and therefore produces 28 acceptable parts.

Explain whether this follows from the assumptions. Calculate the expected accepted
quantity, and distinguish an expected quantity from an actual integer observation.
Return a concise answer, the calculation, and any relevant assumption. Do not claim
to have run code or consulted external sources.
